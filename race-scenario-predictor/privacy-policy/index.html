「競馬展開予想」プライバシーポリシー

【運営者名】（以下「運営者」）は、スマートフォン向けアプリ「競馬展開予想」（以下「本アプリ」）における利用者の情報の取り扱いについて、以下のとおり定めます。

1. 運営者が取得する情報

運営者が本アプリを通じて利用者の個人情報を取得することはありません。

本アプリで選んだレース条件・作成した隊列・表示の設定は、利用者の端末の中にだけ保存され、運営者を含む外部へ送信されることはありません。これらは本アプリを削除すると端末から消去されます。

2. 広告の配信

本アプリは、広告の配信に Google LLC の「Google AdMob」を利用しています。Google AdMob は、広告の配信・効果の測定・不正の防止のために、利用者の端末から次のような情報を自動的に収集することがあります。

  • 広告識別子（Android の広告 ID。iOS の IDFA は、トラッキングを許可した場合のみ。「3. トラッキングの許可と、興味に合わせた広告の停止」を参照）
  • IP アドレス、端末の機種・OS のバージョンなどの端末の情報
  • IP アドレスから推定されるおおよその位置
  • 広告の表示・タップなどの利用状況
  • クラッシュや動作の状況などの診断情報

収集された情報は、Google のプライバシーポリシーに従って取り扱われます。その保存期間や削除の方法も、Google の定めによります。詳しくは次のページをご覧ください。

  • Google プライバシーポリシー
  • Google のサービスを使用するサイトやアプリから収集した情報の Google による使用

3. トラッキングの許可と、興味に合わせた広告の停止

iOS では、本アプリを初めて起動したときに、他社のアプリや Web サイトをまたいで利用者の行動を追跡すること（トラッキング）を許可するかをお尋ねします。許可した場合に限り、広告識別子（IDFA）が、利用者の興味に合わせた広告の表示と、広告の効果の測定に使われます。許可しなくても、本アプリのすべての機能を使えます。選択は、端末の「設定」の「プライバシーとセキュリティ」（iOS 15 では「プライバシー」）＞「トラッキング」からいつでも変えられます。端末で「Appからのトラッキング要求を許可」をオフにしている場合はお尋ねせず、許可しなかったものとして扱います。

Android では、端末の設定（Google の「広告」の項目）から広告 ID を削除すると、利用者の興味に合わせた広告の表示を止められます（リセットは、広告 ID を新しいものに置き換えるだけです）。

4. 第三者への提供

運営者は利用者の個人情報を取得しないため、第三者へ提供することはありません。広告の配信にともなう Google への情報の送信は、「2. 広告の配信」のとおりです。運営者は、本アプリが情報を送る第三者（Google）が、このポリシーおよび App Store の審査ガイドラインが求めるのと同等以上の保護を利用者の情報に与えることを確認しています。

5. このポリシーの変更

運営者は、必要に応じてこのポリシーを変更することがあります。変更後のポリシーは、このページに掲載した時点から効力を生じます。
